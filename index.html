02. About Me

Halo! Saya Nabillah Umi Purnama, mahasiswa semester 5 D-IV Teknik Informatika di Politeknik Negeri Malang. Saat ini, saya sedang mencari kesempatan magang di bidang Full-Stack Development, Backend Development, Database Development, Frontend Development, maupun Mobile Development.

Saya memiliki pengalaman dalam pengembangan aplikasi web secara Full-Stack, mulai dari membangun antarmuka pengguna (frontend), mengembangkan logika dan fitur aplikasi (backend), hingga merancang dan mengelola database relasional. Teknologi yang pernah saya gunakan meliputi PHP, Laravel, HTML, JavaScript, MySQL, dan PostgreSQL.

Selain pengembangan web, saya juga memiliki pengalaman menggunakan Python dalam proyek perkuliahan serta mengembangkan aplikasi mobile menggunakan Flutter dan Dart. Saya juga menggunakan Figma untuk merancang antarmuka dan pengalaman pengguna (UI/UX).

Dalam berbagai proyek perkuliahan, saya telah berkontribusi dalam pengembangan marketplace Bekaswit, sistem informasi Laboratorium Business Analytics, serta CaFind yang melibatkan pengembangan machine learning, backend, dan aplikasi mobile. Melalui proyek tersebut, saya memperoleh pengalaman dalam mengembangkan fitur aplikasi, mengelola database, serta membangun sistem berdasarkan kebutuhan pengguna.
